# Security Policy

## Supported versions

Security fixes are applied to the latest release. Pre-release snapshots and
older releases are not maintained as separate security branches.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting for the
[`bonan-group/symmetrix-xl`](https://github.com/bonan-group/symmetrix-xl/security/advisories/new)
repository. Include affected versions, reproduction steps, impact, and any
known mitigations.

The maintainers will acknowledge a report, assess its scope, and coordinate a
fix and disclosure. Please avoid sharing vulnerability details publicly until
a remediation or disclosure plan has been agreed.
